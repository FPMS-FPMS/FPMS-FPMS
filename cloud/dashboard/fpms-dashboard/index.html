POINT AT A ROVER
The IP override is not a troubleshooting afterthought. mDNS resolution is per-resolver, not per-machine — fpms-rover1.local has resolved from one language's resolver and failed from another's on the same box at the same time, so "ping works" does not prove the browser will resolve it. Find the address on your router or hotspot's client list.

The thing name does not appear in any ROS topic name — it is the MQTT root the Pi-side bridge subscribes, and it is checked against the hardware_id the rover publishes on /diagnostics.

The browser dials this address directly. On WSL that connection does not traverse the WSL network at all — only this page is served from WSL. Saved in this browser's localStorage; ?rover=host:port&thing=name overrides it for one visit.
